How to use cmds

From installing to keeping an eye on your agents and answering them from your phone. Every screenshot is the real app with demo data.

1Install and first launch

  1. Open the DMG and drag cmds.app to Applications (or ~/Applications), then open it from there. To build from source, see the README (needs Xcode, XcodeGen and Zig).
  2. If the macOS firewall is on, macOS asks about incoming connections. Choose Allow if you want to use the iPhone/iPad companion; the terminal works either way.
  3. Allow notifications, so panes that need you can notify you while cmds is in the background.
  4. Optional: cmds › Install Command Line Tool… links /usr/local/bin/cmds, so cmds also works in other terminals (terminals inside cmds have it already).

cmds opens with one workspace: a terminal in your home directory.

2Workspaces and splits

  • ⌘N opens a workspace, ⌘1…⌘9 switch, ⇧⌘R (or a double-click) renames. Drag rows to reorder.
  • ⌘D splits right, ⇧⌘D down. ⌥⌘ + arrows move between panes, ⇧⌘↩ zooms a pane, ⌘W closes it.
  • Each sidebar row shows the git branch, directory, listening ports, the agent's state and task, and the latest notification. ⌥⌘F filters; View › Group Workspaces by Project groups them.
  • When a program in a pane you are not looking at sends a notification (OSC 9/777, the bell, cmds notify), the pane lights up with an orange ring. ⇧⌘U jumps to the latest.

3Tiled view

Show several workspaces side by side as live tiles you can type in.

  • ⌘-click (add/remove) or ⇧-click (range) rows in the sidebar, and the content area tiles them.
  • View › Tile All Workspaces (⌃⌘T) tiles everything, up to nine; press it again for one workspace.
  • You can also drag a sidebar row onto the content area (an edge puts it beside, above or below; the middle swaps). Drag a tile's header to move it, or onto the sidebar to remove it.
  • Tile headers show the state and task; a tile that needs you gets the ring. ⇧⌘↩ shows one tile alone.
  • Claude Code subagents (Task / Agent tool) appear as cards under the tile: type and description, current action, elapsed time and tokens (needs the subagent hooks).

4Browser and preview

  • ⇧⌘B opens a browser to the right of the terminal. ⌘L address bar, ⌘R reload, ⌘[ / ⌘] back / forward.
  • ⇧⌘O (File › Open in Preview…) or ⌘-click on a path printed in the terminal shows the file in a preview pane: images, PDF, video, Office and text through Quick Look, rendered Markdown, coloured diffs.
  • Previews reload when the file changes, so reports and images an agent writes show up right away.

5The cmds command

Every cmds terminal knows which pane it is (CMDS_PANE_ID), so cmds acts on the pane you run it in.

cmds ls                                   # workspaces and panes
cmds split down -- npm run dev            # dev server in a new pane below
cmds browser open http://localhost:3000   # open it in a browser pane
cmds open README.md                       # preview a file
git diff | cmds open --diff -             # coloured diff
make test; cmds notify "tests done: $?"   # light this pane when finished
cmds stats                                # CPU and memory per workspace and for the Mac

cmds --help and cmds <command> --help list everything; every command prints JSON with --json.

6Setting up Claude Code and Codex

Notifications and state (hooks)

Add to ~/.claude/settings.json (or a project's .claude/settings.json). When Claude asks for permission or input, the row shows Needs Input and the pane lights up; when a turn ends it shows Done, and Working again once you answer. SubagentStart / SubagentStop feed the subagent cards and the “Sub 3” count in the sidebar.

{
  "hooks": {
    "Notification": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "Stop": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "UserPromptSubmit": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "SubagentStart": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "SubagentStop": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ]
  }
}

Usage and limits (status line)

Add one line to your status-line script after it reads its input (input=$(cat)). The sidebar then shows model, context, cost and the 5-hour / 7-day limits. Session resume needs this too.

[ -n "$CMDS_PANE_ID" ] && command -v cmds >/dev/null 2>&1 && printf '%s' "$input" | cmds hook claude-status >/dev/null 2>&1

Without a status-line script, "statusLine": {"type": "command", "command": "cmds hook claude-status"} works as well (the status line then stays empty).

Skill and Codex

  • Claude Code skill: copy integrations/claude/skills/cmds/SKILL.md to ~/.claude/skills/cmds/, and Claude uses helper panes, the browser and previews without stealing your focus.
  • Codex: usage needs no setup. For notifications set notifications = true, notification_method = "osc9" and notification_condition = "always" under [tui] in ~/.codex/config.toml.

Reading the sidebar

  • Working (blue), Needs Input (orange), Done (green), Idle and Stopped (grey)
  • The second line is the agent's task (Claude Code's title), with “Sub 3” while subagents run
  • Model, context use and the session's cost
  • At the bottom: account limits (5-hour, 7-day, Claude's spend limit) and the Mac's CPU and memory; orange from 80 %, red from 95 %

7Pairing an iPhone/iPad

  1. On the Mac choose cmds › Pair iPhone/iPad…. The window shows a QR code and a 6-digit code (valid only while it is open).
  2. In the companion tap Scan Pairing Code and scan the QR code. Without the camera, pick the Mac, compare its identity and enter the 6-digit code.
  3. Once connected you see the Mac's workspaces. Open one to see its terminal live and answer with the key bar or the input field.

Not on the same network? Without Wi‑Fi the phone uses Bluetooth LE, and away from home it goes through your own SSH server set up under cmds › Remote Access via SSH…. Every path carries the same TLS session pinned to your Mac's certificate.

Get the free iPhone and iPad app, cmds Companion, from the App Store.

8SSH workspaces

  • ⇧⌘N (File › New SSH Workspace…) asks for a host, completed from ~/.ssh/config; your keys and jump hosts work as usual.
  • cmds forwards a restricted socket over the same SSH connection. Run Pane › Install Remote Helper… once, and cmds notify and the Claude Code hooks work on the server too: notifications and usage reach your sidebar.
  • When the connection drops the pane says “Disconnected”; ⌘R or Reconnect runs the same command again.
