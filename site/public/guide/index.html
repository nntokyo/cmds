使い方

インストールから、エージェントを見守る設定、iPhone からの返答まで。画面はすべて実際のアプリ（デモ用のデータ）です。

1インストールと初回起動

  1. DMG を開き、cmds.app を「アプリケーション」フォルダ（または ~/Applications）にドラッグして開きます。ソースからビルドする場合は README の手順を参照してください（Xcode、XcodeGen、Zig が必要）。
  2. macOS のファイアウォールが有効な場合、受信接続の確認が出ます。iPhone/iPad コンパニオンを使うなら「許可」を選びます（ターミナル自体はどちらでも動きます）。
  3. 通知も許可してください。cmds が背面にあるときに、入力待ちのペインを macOS の通知で知らせます。
  4. ウィンドウを閉じても cmds とターミナル（エージェント）は動き続けます。Dock のアイコンか ⌘N でウィンドウが戻ります。エージェントの実行中に終了しようとすると確認が出ます。
  5. 任意：cmds › コマンドラインツールをインストール… で /usr/local/bin/cmds へのリンクを作ると、ほかのターミナルからも cmds を使えます（cmds の中のターミナルでは最初から使えます）。

起動すると、ホームディレクトリのターミナルを 1 つ持つワークスペースが開きます。

2ワークスペースと分割

  • ⌘N で新しいワークスペース、⌘1…⌘9 で切り替え、⇧⌘R（またはダブルクリック）で名前を変更。行はドラッグで並べ替えられます。
  • ⌘D で右に、⇧⌘D で下に分割。⌥⌘＋矢印でペイン間を移動、⇧⌘↩ でペインをズーム、⌘W で閉じます。
  • サイドバーの各行には、Git ブランチ、ディレクトリ、待ち受けポート、エージェントの状態とタスク、最新の通知が表示されます。⌥⌘F で絞り込み、表示 › ワークスペースをプロジェクトでまとめる も使えます。
  • 見ていないペインのプログラムが通知（OSC 9/777、ベル、cmds notify）を出すと、そのペインがオレンジのリングで光ります。⇧⌘U で最新の通知へジャンプ。

3タイル表示

複数のワークスペースを、それぞれ入力もできるライブタイルとして並べます。

  • サイドバーで ⌘-クリック（追加・解除）や ⇧-クリック（範囲）で選ぶと、すぐにタイルになります。
  • 表示 › すべてのワークスペースを並べて表示（⌃⌘T）で全部を並べ、もう一度押すと 1 つに戻ります。最大 9 枚。
  • サイドバーの行をコンテンツ領域へドラッグしても並べられます（端に落とすと隣や上下へ、中央なら入れ替え）。タイルの見出しをドラッグして移動、サイドバーへ戻すと外れます。
  • タイルの見出しに状態とタスクが出て、入力待ちのタイルはリングで光ります。⇧⌘↩ で 1 枚を大きく表示。
  • Claude Code のサブエージェント（Task / Agent ツール）は、タイルの下にカードで表示されます。種類と説明、いま実行中の操作、経過時間、トークン数（サブエージェント用のフックが必要）。

4ブラウザとプレビュー

  • ⇧⌘B でターミナルの右にブラウザを開きます。⌘L でアドレスバー、⌘R で再読み込み、⌘[ / ⌘] で戻る・進む。
  • ⇧⌘O（ファイル › プレビューで開く…）、またはターミナルに表示されたパスの ⌘-クリックで、ファイルをプレビューペインに表示。画像、PDF、動画、Office、テキストは Quick Look、Markdown は整形表示、diff は色付きで表示します。
  • ファイルが変更されると自動で再読み込みされます。エージェントが書いたレポートや画像をそのまま確認できます。

5cmds コマンド

cmds のターミナルは自分がどのペインかを知っている（CMDS_PANE_ID）ので、cmds は実行したペインを基準に動きます。

cmds ls                                   # ワークスペースとペインの一覧
cmds split down -- npm run dev            # 下に新しいペインを作って開発サーバーを起動
cmds browser open http://localhost:3000   # ブラウザペインで開く
cmds open README.md                       # ファイルをプレビュー
git diff | cmds open --diff -             # diff を色付きで表示
make test; cmds notify "tests done: $?"   # 終わったらこのペインを光らせる
cmds stats                                # ワークスペースごとと Mac 全体の CPU・メモリ

cmds --help と cmds <コマンド> --help で全コマンドを確認できます。すべて --json で JSON を出力します。

6Claude Code と Codex の設定

通知と状態（フック）

~/.claude/settings.json（またはプロジェクトの .claude/settings.json）に追加します。許可や入力を求めると「入力待ち」になってリングが光り、ターンが終わると「完了」、入力すると「作業中」に戻ります。SubagentStart / SubagentStop はサブエージェントのカードと、サイドバーの「サブ 3」のような数の表示に使います。

{
  "hooks": {
    "Notification": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "Stop": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "UserPromptSubmit": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "SubagentStart": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ],
    "SubagentStop": [
      { "hooks": [{ "type": "command", "command": "command -v cmds >/dev/null && cmds hook claude || true" }] }
    ]
  }
}

使用量と上限（ステータスライン）

ステータスラインのスクリプトが入力を読んだ（input=$(cat)）あとに 1 行追加します。モデル、コンテキスト、料金、5 時間・7 日間の上限がサイドバーに出ます。セッションの再開にもこの設定が必要です。

[ -n "$CMDS_PANE_ID" ] && command -v cmds >/dev/null 2>&1 && printf '%s' "$input" | cmds hook claude-status >/dev/null 2>&1

ステータスラインのスクリプトがなければ、"statusLine": {"type": "command", "command": "cmds hook claude-status"} だけでも動きます（表示は空になります）。

スキルと Codex

  • Claude Code のスキル：integrations/claude/skills/cmds/SKILL.md を ~/.claude/skills/cmds/ にコピーすると、Claude がフォーカスを奪わずに補助ペインやブラウザ、プレビューを使うようになります。
  • Codex：使用量は設定不要です。通知は ~/.codex/config.toml の [tui] に notifications = true、notification_method = "osc9"、notification_condition = "always" を設定します。

サイドバーの見方

  • 作業中（青）・入力待ち（オレンジ）・完了（緑）・待機・停止（グレー）
  • 2 行目はエージェントのタスク（Claude Code のタイトル）。サブエージェントの実行中は「サブ 3」のように数が出ます
  • モデル、コンテキストの使用率、そのセッションの料金
  • 最下部はアカウントの上限（5 時間・7 日間、Claude の利用上限額）と Mac 全体の CPU・メモリ。80% でオレンジ、95% で赤

7iPhone/iPad のペアリング

  1. Mac で cmds › iPhone/iPadとペアリング… を選ぶと、QR コードと 6 桁のコードが表示されます（ウィンドウを開いている間だけ有効）。
  2. iPhone/iPad のコンパニオンで「ペアリングコードをスキャン」をタップして QR コードを読み取ります。カメラを使わない場合は、Mac を選んで ID を照合し、6 桁のコードを入力します。
  3. 接続すると、Mac のワークスペースの一覧が表示されます。ワークスペースを開くとターミナルの画面がライブで表示され、キーバーや入力欄から返答できます。

同じネットワークにいなくても、Wi‑Fi がなければ Bluetooth LE で、外出先では cmds › SSH経由のリモートアクセス… で設定したあなたの SSH サーバーを中継して接続します。どの経路でも、Mac の証明書にピン留めした同じ TLS 接続です。

iPhone・iPad のアプリ「cmds Companion」は App Store から無料で入手できます。

8SSH ワークスペース

  • ⇧⌘N（ファイル › 新規SSHワークスペース…）でホストを入力します。~/.ssh/config のホストが補完され、鍵やジャンプホストもいつも通り使われます。
  • cmds は制限付きのソケットを同じ SSH 接続でサーバーへ転送します。ペイン › リモートヘルパーをインストール… を一度実行すると、サーバー上でも cmds notify や Claude Code のフックが動き、通知と使用量が手元のサイドバーに届きます。
  • 接続が切れるとペインに「切断されました」と表示され、⌘R か「再接続」で同じコマンドを再実行します。
