プライバシーポリシー

合同会社N.N.（以下「当社」）は、cmds の Mac アプリ、iPhone/iPad アプリ（以下「本アプリ」）および本サイト（cmds.n-n.tokyo）における情報の取り扱いを次のとおり定めます。

1. 本アプリが収集する情報

本アプリは、利用状況などの情報を当社またはその他の第三者に送信しません。テレメトリ、利用状況の解析、クラッシュレポートの自動送信、広告、アカウント登録の仕組みはありません。

Mac アプリは、アップデートを確認するため、本サイト（cmds.n-n.tokyo）から 1 日 1 回（前回から 1 日以上たっていれば起動時にも）更新情報を取得し、新しい版があれば GitHub から自動でダウンロードして、cmds の終了時にインストールします。この通信では、通常のウェブの閲覧と同じく、IP アドレスと、アプリと Sparkle のバージョンなどを含むユーザーエージェントが送られます。cmds › 設定… › アップデート で、自動確認と自動ダウンロードをそれぞれオフにできます。

2. お使いの端末に保存される情報

  • ワークスペースの構成、各ペインのディレクトリ・URL・プレビュー中のファイル・SSH ホスト、再開用のエージェントのセッション ID などは、Mac の ~/Library/Application Support/cmds/ に保存されます。
  • iPhone/iPad との同期用の鍵と証明書は Mac のキーチェーンに、ペアリングした端末の情報（トークンはハッシュのみ）は上記のフォルダに保存されます。
  • 設定（言語、スリープ防止など）は macOS / iOS の標準の設定領域に保存されます。

これらはアプリを削除し、上記のデータを消すことでいつでも削除できます。

3. AI コーディングエージェントの情報

本アプリは、Claude Code のフックとステータスラインから渡される情報（イベント名、通知の文、モデル、コンテキスト、料金、利用上限など）と、Codex のセッションファイルのうちセッション ID・ディレクトリ・使用量・モデルを Mac の中で読み取り、画面に表示します。プロンプトは読み取りません。会話の内容は、通知として表示する Claude の最後の返答の 1 行目を除いて扱いません。サブエージェントについては、その記録ファイルの末尾から直近のツール名と短い対象、トークン数だけを読み取ります。これらの情報は Mac の外へは、あなたがペアリングした iPhone/iPad への同期以外では送られません。

4. iPhone/iPad との同期

同期は、あなたの Mac とあなたがペアリングした iPhone/iPad の間で、Mac の証明書にピン留めした TLS 1.3 で暗号化された接続を通じて直接行われます。経路はローカルネットワーク、Bluetooth LE、またはあなたが設定した SSH サーバーのいずれかで、当社のサーバーは介在しません。SSH サーバーを中継に使う場合、そのサーバーは暗号化されたデータを中継するだけで内容を読むことはできません。

5. アプリ内ブラウザ

アプリ内ブラウザで開いたウェブサイトには、通常のブラウザと同様にあなたの IP アドレスなどが送信され、各サイトのポリシーが適用されます。アドレスバーに URL ではない語句を入力すると、Google 検索に送信されます。

6. 本サイト

本サイトは Google の Firebase Hosting で配信しています。配信のために、Google がアクセスの記録（IP アドレス、ユーザーエージェント、日時など）を処理することがあります。

本サイトは、利用状況を把握して改善するため、Google LLC（米国）の Google アナリティクスを使用しています（このプライバシーポリシーのページを除く）。

  • 送信される情報：閲覧したページの URL とタイトル、参照元、クリックしたリンク（ダウンロード、App Store、GitHub など）やスクロールなどの操作、ブラウザ・OS・端末の種類、言語、画面サイズ、IP アドレスから推定したおおよその地域、日時、Cookie に保存した識別子。
  • 送信先と利用目的：Google LLC に送信されます。当社は利用状況の把握とサイトの改善に使います。Google による利用は Google のポリシーをご覧ください。
  • Cookie：本サイト専用の Cookie（有効期限 13 か月）を使い、当社の他のサイトとは共有しません。
  • 欧州経済領域、英国、スイスからのアクセス：Cookie は使わず、上記の情報を識別子なしで送信します。法的根拠はサイトの利用状況を把握して改善するという当社の正当な利益で、Google LLC への移転は EU-米国データプライバシーフレームワーク（英国・スイスの枠組みを含む）に基づきます。アクセス・削除・異議（下の設定で送信を止められます）の権利があり、監督機関に苦情を申し立てることもできます。ご連絡は 7 項の窓口までお願いします。
  • 保存期間：イベント単位のデータは 2 か月、ユーザー単位のデータは最後の訪問から 14 か月で削除されます。集計済みのレポートは残ります。
  • Google シグナルや広告のための機能は使用しません。本サイトは広告を表示しません。当社が Google アナリティクスで氏名やメールアドレスなどを扱うことはありません。

下の設定、オプトアウト アドオン、またはブラウザの設定で送信を止められます。


オフにすると Google アナリティクスを読み込まず、その Cookie を削除します。この設定は、このブラウザに 1 年間保存されます（Cookie と localStorage）。
