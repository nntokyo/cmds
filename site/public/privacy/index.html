プライバシーポリシー

合同会社N.N.（以下「当社」）は、cmds の Mac アプリ、iPhone/iPad アプリ（以下「本アプリ」）および本サイト（cmds.n-n.tokyo）における情報の取り扱いを次のとおり定めます。

1. 本アプリが収集する情報

本アプリは、当社またはその他の第三者に対して情報を送信しません。テレメトリ、利用状況の解析、クラッシュレポートの自動送信、広告、アカウント登録の仕組みはありません。

2. お使いの端末に保存される情報

  • ワークスペースの構成、各ペインのディレクトリ・URL・プレビュー中のファイル・SSH ホスト、再開用のエージェントのセッション ID などは、Mac の ~/Library/Application Support/cmds/ に保存されます。
  • iPhone/iPad との同期用の鍵と証明書は Mac のキーチェーンに、ペアリングした端末の情報（トークンはハッシュのみ）は上記のフォルダに保存されます。
  • 設定（言語、スリープ防止など）は macOS / iOS の標準の設定領域に保存されます。

これらはアプリを削除し、上記のデータを消すことでいつでも削除できます。

3. AI コーディングエージェントの情報

本アプリは、Claude Code のフックとステータスラインから渡される情報（イベント名、通知の文、モデル、コンテキスト、料金、利用上限など）と、Codex のセッションファイルのうちセッション ID・ディレクトリ・使用量・モデルを Mac の中で読み取り、画面に表示します。プロンプトは読み取りません。会話の内容は、通知として表示する Claude の最後の返答の 1 行目を除いて扱いません。サブエージェントについては、その記録ファイルの末尾から直近のツール名と短い対象、トークン数だけを読み取ります。これらの情報は Mac の外へは、あなたがペアリングした iPhone/iPad への同期以外では送られません。

4. iPhone/iPad との同期

同期は、あなたの Mac とあなたがペアリングした iPhone/iPad の間で、Mac の証明書にピン留めした TLS 1.3 で暗号化された接続を通じて直接行われます。経路はローカルネットワーク、Bluetooth LE、またはあなたが設定した SSH サーバーのいずれかで、当社のサーバーは介在しません。SSH サーバーを中継に使う場合、そのサーバーは暗号化されたデータを中継するだけで内容を読むことはできません。

5. アプリ内ブラウザ

アプリ内ブラウザで開いたウェブサイトには、通常のブラウザと同様にあなたの IP アドレスなどが送信され、各サイトのポリシーが適用されます。アドレスバーに URL ではない語句を入力すると、Google 検索に送信されます。

6. 本サイト

本サイトは Google の Firebase Hosting で配信しています。配信のために、Google がアクセスの記録（IP アドレス、ユーザーエージェント、日時など）を処理することがあります。本サイトは利用状況を把握するため Google アナリティクスを使用しています。Google アナリティクスは Cookie を使い、閲覧したページ、リンクのクリック（ダウンロード、App Store、GitHub）、おおよその地域、ブラウザや端末の種類などを Google に送信します。当社が受け取るのは個人を特定しない集計結果だけです。データの扱いは Google のポリシーをご覧ください。下の設定、オプトアウト アドオン、またはブラウザの設定で送信を止められます。本サイトは広告を使用しません。


オフにすると Google アナリティクスを読み込まず、その Cookie を削除します。設定はこのブラウザに保存されます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、合同会社N.N.（info@n-n.tokyo）までご連絡ください。

8. 改定

本ポリシーを改定する場合は、本ページで告知します。
