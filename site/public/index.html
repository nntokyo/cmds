AIエージェントを、
並べて走らせるターミナル。

cmds は Claude Code や Codex を何本も同時に動かすための、macOS ネイティブのターミナルワークスペースです。どのエージェントが作業中で、どれがあなたの入力を待っているかがサイドバーで分かり、待っているペインはオレンジのリングで光ります。

Mac 版をダウンロード macOS 14 以降・Apple シリコン 使い方を見る

無料・オープンソース（GPL-3.0）。アカウント登録もテレメトリもありません。

Features

エージェント時代のための機能

普段のシェルはそのままに、エージェントを見守るための情報と道具を Mac ネイティブの速さで。

縦タブのワークスペース

ワークスペースごとに Git ブランチ、ディレクトリ、待ち受けポート、エージェントの状態（作業中・入力待ち・完了）とタスク名を表示。フィルタやプロジェクト別のグループ化も。

通知リング

エージェントが許可や入力を求めると、そのペインがオレンジのリングで光り、サイドバーにメッセージが出ます。⇧⌘U で最新の通知へジャンプ。OSC 9/777・ベル・cmds notify に対応。

アプリ内ブラウザ

WebKit のブラウザをターミナルの隣に。開発サーバーの画面を確認でき、cmds browser eval や snapshot でエージェントからも操作できます。

分割とタイル表示

右・下への入れ子の分割、ペインのズーム。複数のワークスペースを最大 9 枚のライブタイルとして並べ、5 つの Claude Code を同時に見ることも。サイドバーからドラッグして配置できます。

ファイルプレビュー

画像、PDF、動画、Office（Quick Look）、GitHub 風の Markdown、色付きの diff。ファイルが変わると自動で再読み込み。ターミナル上のパスを ⌘-クリックでも開けます。

CLI とソケット API

同梱の cmds コマンドで分割、入力、画面の読み取り、通知、ブラウザ操作、統計を。すべて --json 対応で、スクリプトやエージェントから扱えます。

libghostty の GPU 描画

ターミナルの描画は Ghostty のエンジン（libghostty）による Metal の GPU 描画。true color、xterm-ghostty の terminfo とシェル統合を同梱。

Swift と AppKit でネイティブ

Electron ではなく Swift と AppKit で書かれた Mac アプリ。メニュー、ショートカット、通知、Quick Look など macOS の作法に沿って動きます。

SSH ワークスペース

いつもの ssh と ~/.ssh/config をそのまま使い、制限付きのソケットをサーバーへ転送。サーバー上のエージェントの通知や使用量も手元に届き、切断時は再接続ボタンが出ます。

スリープさせない

cmds の実行中は Mac のアイドルスリープを防止。長いエージェントの作業も止まりません。必要なら蓋を閉じても動かし続ける設定も（オプトイン）。

セッションの復元

再起動後もワークスペース、分割、ディレクトリ、URL が戻り、Claude Code / Codex のセッションの再開を提案します。書き出し・読み込みで別の Mac へも移せます。

日本語と英語

Mac アプリも iPhone/iPad アプリも日本語と英語の UI に対応。言語はメニューから切り替えられます。

For AI agents

Claude Code と Codex のために

cmds はエージェントの「今」をサイドバーに集めます。

  • 状態：Claude Code のフックとタイトルから、作業中・入力待ち・完了・待機・停止を表示。
  • 使用量と上限：ステータスライン（cmds hook claude-status）からモデル、コンテキスト、料金、5 時間・7 日間の利用上限を表示。80% でオレンジ、95% で赤。
  • Codex：設定不要。セッションファイルから ID・ディレクトリ・使用量・モデルだけを読み、会話内容は読みません。
  • サブエージェント：Claude Code のサブエージェント（Task / Agent ツール）をタイルの下にカードで表示。種類、実行中の操作、経過時間、トークン数が分かります。
  • セッション再開：cmds を再起動すると、各ペインで動いていたセッションを claude --resume / codex resume で再開できます（確認・常に・しない を選択）。
  • Claude Code のスキル：フォーカスを奪わずに補助ペインを開き、開発サーバーやブラウザ、プレビューを使う方法を Claude に教えます。

iPhone & iPad

離れていても、エージェントの呼びかけに応える

iPhone/iPad コンパニオンは Mac のワークスペースとターミナル画面をミラーし、入力待ちになったら通知します。キーバーやハードウェアキーボードからそのまま返答できます。「承認」「別案」などの定型文や claude・codex の起動は、ショートカットボタンをタップするだけです。

  • QR コードでペアリング。通信は Mac 自身の証明書にピン留めした TLS 1.3。
  • 同じネットワーク（ピアツーピア Wi‑Fi 含む）、Wi‑Fi がなければ Bluetooth LE、外出先ではあなたの SSH サーバー経由で接続。
  • CPU・メモリ、エージェントの使用量と上限、画像や PDF のプレビューも表示。
  • 当社のサーバーやアカウントは使いません。

iOS/iPadOS 17 以降。App Store で無料配信中。
